1. IDEA PRINCIPAL QUE DEBES TRANSMITIR
--------------------------------------

El software convierte diez años de datos climáticos históricos en indicadores,
gráficos, mapas y análisis interactivos para comparar cuándo y dónde se
concentra la exposición a heladas en Puno.

Frase corta para memorizar:

"Nuestro dashboard transforma datos históricos de 2015 a 2024 en evidencia
interactiva para comparar el riesgo de heladas entre las trece capitales
provinciales de Puno. Apoya la priorización, pero no reemplaza las alertas
oficiales ni pronostica el clima futuro".


2. PREPARACIÓN ANTES DE EXPONER
-------------------------------

Haz esto entre 10 y 15 minutos antes:

1. Dentro de la carpeta del proyecto ejecuta:

   .\.venv\Scripts\python.exe -m streamlit run app.py

   Si no existe el entorno .venv, en esta computadora también funciona:

   python -m streamlit run app.py

2. Abre http://localhost:8501 en Chrome o Edge.
3. Usa Ctrl + 0 para restaurar el zoom. Si no entran los ocho KPI, usa
   Ctrl + - una o dos veces hasta llegar a 80 % o 90 %.
4. Entra una vez a "Analisis multidimensional" y espera a que terminen de
   calcularse los modelos. La primera carga puede tardar de 20 a 30 segundos.
5. Regresa a "app" y pulsa "Restablecer todos los filtros".
6. Comprueba esta configuración inicial:

   - Atajo temporal: Todo el periodo.
   - Provincias: todas.
   - Temporadas: todas.
   - Umbral: Helada meteorológica (Tmín ≤ 0 °C).
   - Analizar sólo días con helada: desactivado.

7. Cierra pestañas, notificaciones y programas que puedan distraer.
8. Mantén abierta la diapositiva o captura de respaldo por si falla Internet,
   aunque el dashboard puede trabajar localmente después de instalarse.

4. QUÉ HACE REALMENTE EL SOFTWARE
---------------------------------

- Analiza datos históricos diarios de 2015–2024.
- Trabaja con 47.489 observaciones de trece capitales provinciales.
- Usa ERA5-Land/ERA5 como fuente principal y MERRA-2 como validación externa.
- Filtra por fecha, provincia, piso ecológico, altitud, temporada, temperatura,
  umbral de helada, variable analítica y controles de calidad.
- Mantiene los filtros cuando el usuario cambia de página.
- Recalcula KPI, rankings, series, mapas e interpretaciones automáticas.
- Compara helada meteorológica de 0 °C y exposición agronómica de 3 °C.
- Presenta distribuciones, pruebas estadísticas y tendencias históricas.
- Incluye correlaciones, PCA, K-Means, Ward, Isolation Forest y Random Forest.
- Permite descargar la selección como CSV, Excel y resumen Markdown.
- Documenta fuentes, limpieza, fórmulas, diccionario y limitaciones.


5. QUÉ NO HACE — NO PROMETAS ESTO AL JURADO
-------------------------------------------

- NO recibe datos meteorológicos en vivo. Los datos terminan el 31/12/2024.
- NO pronostica si mañana habrá una helada.
- NO envía SMS, correos, notificaciones ni alarmas automáticas.
- NO reemplaza los avisos oficiales de SENAMHI.
- NO representa cada distrito, comunidad, parcela o microclima.
- NO mide daños reales en cultivos, ganado, rendimiento o pérdidas económicas.
- NO demuestra que una variable cause otra; muestra asociaciones y patrones.
- NO demuestra cambio climático con sólo diez años de datos.
- NO convierte los grupos de K-Means en fronteras climáticas oficiales.
- NO considera el índice 0–100 como una escala oficial o calibrada con pérdidas.
- NO interpreta automáticamente toda anomalía como error.
- NO tiene usuarios, inicio de sesión, edición de datos ni base transaccional.

Si aparece la frase "calculado en tiempo real", explica que significa
"recalculado inmediatamente al mover filtros", no datos climáticos en vivo.

7. RESPUESTAS RÁPIDAS SI EL JURADO PREGUNTA
-------------------------------------------

¿EL SOFTWARE TRABAJA EN TIEMPO REAL?
"No recibe clima en vivo. Recalcula en el momento los datos históricos que el
usuario selecciona. El periodo disponible termina en diciembre de 2024".

¿PUEDE PREDECIR LA HELADA DE MAÑANA?
"No en su versión actual. El Random Forest es explicativo y fue evaluado sobre
datos históricos. Para pronóstico operativo necesitaríamos integrar pronósticos
meteorológicos, validación continua y un mecanismo oficial de alerta".

¿POR QUÉ USAN 0 °C Y 3 °C?
"Cero grados identifica la helada meteorológica. Tres grados es un umbral
preventivo de exposición para cultivos sensibles; no confirma daño real".

¿POR QUÉ ERA5-LAND?
"Porque su resolución aproximada de nueve kilómetros permite diferenciar mejor
los puntos provinciales. MERRA-2 es más gruesa y se usa sólo como contraste".

¿EL MAPA REPRESENTA TODA LA PROVINCIA?
"No. Cada punto corresponde a la celda cercana a la capital provincial. Es una
comparación reproducible, pero no captura todos los microclimas".

¿EL ÍNDICE DE RIESGO ES OFICIAL?
"No. Es un índice compuesto del proyecto con pesos expertos y sirve para
comparación interna. Todavía debe calibrarse con pérdidas observadas en campo".

¿POR QUÉ EL AUC DEL MODELO ES ALTO?
"Se usó partición cronológica y se excluyeron las variables que definen
directamente el evento para reducir fuga. Aun así, lo tratamos como asociación
histórica, no como desempeño garantizado para un pronóstico futuro".

¿PUEDEN AFIRMAR QUE LAS HELADAS ESTÁN DISMINUYENDO?
"No. La dirección estimada fue descendente, pero las pruebas no alcanzaron
significancia estadística y diez años no constituyen una normal climática".

¿UNA ANOMALÍA ES UN DATO MALO?
"No necesariamente. Significa que la combinación de variables es poco frecuente
y debe revisarse; por eso no se elimina automáticamente".
